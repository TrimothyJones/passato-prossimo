# Contributing During The Public Alpha

The first public round is focused on observation and feedback rather than code
contributions. Bug reports and descriptions of confusing or useful moments are
welcome. Pull requests are paused until the project chooses a long-term source
license and contribution policy.

Please do not post:

- Copyrighted passages, imported books, article text, or media files.
- Private URLs or exported reports containing information you do not want public.
- Account details, API keys, personal information, or private correspondence.

A useful report includes the app version, Windows version, source type, what you
expected, what happened, and whether the problem happened again. The app's
sanitized testing report is optional and is never uploaded automatically.

AI-assisted development is part of this project's documented process. Product
direction, testing decisions, and release responsibility remain with the project
owner; generated implementation is reviewed through source inspection, focused
tests, packaging checks, and real use.
