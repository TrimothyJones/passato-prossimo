## Review workflow

Review in groups of 10: confirm the headword and verb use, inspect all senses and labels, select a learner default only with a recorded reviewer/decision, and check modern sentence examples. Keep secondary senses. Then wire the reviewed batch into Word Lens and test exact matches, inflections, accents, and fallback. Selecting these 50 is not approving them.

Full definitions, source locators, metadata, notes, and held candidates: `../data/research/verbs-002.json`. Unchanged selected HTML: `../data/research/verbs-002-source.json`. Neither file is loaded by the app.
